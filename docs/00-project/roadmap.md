# Roadmap

Status: Proposed

## Phase 0 - Technical POC

Complete: controlled PDF, UDF 0.1, six preflight categories, safe solid-color bleed, CMYK/PDF/X candidate, automated checks.

## Phase 1 - PDF Preflight Alpha

- 200-500 anonymized regression PDFs.
- Two concrete print products and Print Presets.
- Rule schema, evidence model and fixture library.
- Independent PDF/X validation.
- License/engine decision.
- Upload, queue, isolated worker and report API.

## Phase 2 - Controlled Fix Beta

- Approval UI and before/after preview.
- Exact-font resolution and font licensing policy.
- Product-specific color conversion and proof workflow.
- Expanded bleed strategies with confidence gates.
- Job audit and tenant security.

## Phase 3 - Production OS

- Print-provider preset marketplace/integration.
- Rule packs, SLA, observability and billing.
- Human review operations.
- Optional non-PDF adapters only after PDF reliability targets are met.
