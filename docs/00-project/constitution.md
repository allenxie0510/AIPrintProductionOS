# Project Constitution

Status: Accepted

1. **PDF first.** New input formats require an RFC and must normalize into an evidence-bearing contract.
2. **Rules before AI.** Deterministic production requirements live in versioned code and data.
3. **Evidence before verdict.** Every issue must point to a page, object, measurement or structural observation.
4. **No fake quality.** Metadata changes and super-resolution never erase the original effective DPI fact.
5. **No silent font replacement.** Substitution is a reviewable change, not an invisible repair.
6. **Originals are immutable.** Every output is a derivative with provenance and hashes.
7. **Automation is risk-tiered.** Each fix is auto, confirm or manual.
8. **Validate after mutation.** Re-parse, re-run rules, check structure and compare rendering.
9. **Print condition is configuration.** CMYK and PDF/X are defined by a Print Preset, not one universal default.
10. **Claims match evidence.** A generated PDF/X declaration is not certification without independent validation.
11. **Licensing is architecture.** AGPL/commercial decisions are release gates, not a later legal cleanup.
12. **Decisions outlive chats.** Accepted ADRs and specifications are the source of truth.
